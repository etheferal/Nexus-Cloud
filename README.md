# Nexus-Cloud
☁️ NexusCloud — Dağıtık Bulut İzleme & Orkestrasyon Konsolu  Kurumsal bulut mimarilerini, konteyner küme orkestrasyonunu (Kubernetes tarzı pod yönetimi), canlı zaman serisi metrik çizmeyi ve gerçek zamanlı log akış konsolunu tek ekranda sunan kurumsal SaaS simülasyon panosu.  ![JavaScript](https://img.shields.io/badge/JavaScript-ES6+_Canvas-F7DF1E?style=flat&logo=javascript&logoColor=black) ![Cloud Architecture](https://img.shields.io/badge/Architecture-Distributed_Observability-38bdf8?style=flat)  ## 🏗️ Mimari Öne Çıkanlar 1. **Zaman Serisi Çizim Motoru (`HTML5 Canvas`):** CPU, RAM ve Ağ istatistiklerini saniyede 1 kare güncelleyerek akıcı çizgi grafikler oluşturur. 2. **Asenkron Dağıtık Log Akış Konsolu:** Farklı servis kaynaklarından gelen logları seviyelerine (`INFO`, `WARN`, `ERROR`, `SUCCESS`) göre filtreler. 3. **Konteyner Yaşam Döngüsü Simülasyonu:** Pod yeniden başlatma (`restart`), ölçeklendirme ve acil durum tetikleme işlevleri.
